# HSK 4 — учебная студия (публичная демоверсия)

Сайт без сборки, открывается на GitHub Pages.

## Публикация
1. Создайте новый **public** репозиторий на GitHub.
2. Загрузите файлы `index.html` и `.nojekyll` в корень репозитория (Add file → Upload files → Commit changes).
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Через несколько минут откройте адрес `https://USERNAME.github.io/REPOSITORY/`.

## Что работает
Карточки и игры урока 1, грамматические пояснения и 15 тренировочных вопросов; прогресс сохраняется локально в браузере.

## Ограничения
Это **не полная версия на 20 уроков**: остальные уроки не наполнены. Оригинальные учебники, ключи, изображения страниц и MP3 не включены из-за авторских прав. GitHub Pages — публичный статический хостинг и не подходит для защищённого хранения этих материалов. Для синхронизации прогресса между устройствами потребуется backend.
