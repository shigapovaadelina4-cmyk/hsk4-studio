📒 Рабочая тетрадь · Урок 1 简单的爱情

Все 50 оригинальных заданий урока 1 показаны прямо на странице, без PDF. Выбирай часть задания, слушай записи, отмечай ответы и проверяй себя. Для письменных заданий введи свой вариант.

Для заданий 44–50 варианты могут различаться: сайт показывает образец из ключей, но не оценивает свободный ответ автоматически. Пока полностью перенесён урок 1; остальные уроки добавим по очереди.

Урок 1: 32 слова из словаря учебника и 5 дополнительных словосочетаний из текстов. Русские переводы и короткие примеры подготовлены для тренировки; примеры не являются дословными цитатами учебника. Проверка ответов аудирования пока не подключена. Игры и PDF-тетради добавлены в расширенной версии. Не размещай защищённые учебники и аудиозаписи в открытом репозитории без разрешения правообладателя.
